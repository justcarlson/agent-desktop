Desktop automation CLI for AI agents, using native accessibility trees and structured JSON.

```bash
npm install -g agent-desktop      # macOS, Windows, and Linux
agent-desktop version             # Check the installed version
```

## Features

- **Ref-based**: Snapshot an accessibility tree and act on its elements.
- **Cross-platform**: Native binaries and helpers for macOS, Windows, and Linux on x64 and ARM64.
- **Agent-first**: The calling agent observes, acts, and verifies the result.
